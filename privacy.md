# Privacy Policy for AutoScroll

**Last updated: 2026-05-28**

AutoScroll does not collect, store, or transmit any personal information or user data.

## Data Handling

- All keyboard and mouse events are processed locally within the active browser tab to control scrolling behavior
- User preferences (shortcuts, speed, language) are stored locally via Chrome's storage API and never leave your device
- No analytics, no tracking, no telemetry
- No data is sent to any external server

## Permissions

- **storage**: Used solely to save your preferences (shortcuts, speed, etc.) across browser sessions
- **Host permission (all URLs)**: Required to inject the scroll engine into any page you choose to scroll

## Contact

If you have questions about this privacy policy, please open an issue on the extension's GitHub repository.
