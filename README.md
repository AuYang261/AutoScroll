# AutoScroll

一个简洁高效的浏览器自动滚屏扩展，支持键盘和鼠标控制，速度调节直观流畅。

## 功能特点

- 🎯 **快捷启动** - 键盘组合键一键启动/停止滚动
- ⚡ **灵活调速** - 方向键或鼠标滚轮实时调节速度，连续无级调速
- 🔄 **双向滚动** - 支持向上/向下滚动，随时切换方向
- 🎨 **可视化反馈** - 可选的浮层显示当前速度和状态
- ⚙️ **自定义配置** - 快捷键、速度、方向均可自定义

## 使用方法

### 基本操作

1. **启动滚动** - 按 `Ctrl + Space`（默认）
2. **调节速度**
   - 键盘：按 `↑` 加速，按 `↓` 减速（可自定义）
   - 鼠标：按住中键 + 滚轮上下调速
3. **切换方向** - 按 `Ctrl + Shift + Space`
4. **停止滚动** - 再次按 `Ctrl + Space`

### 自定义设置

点击浏览器工具栏中的扩展图标，打开配置面板：

- **快捷键设置** - 可自定义启动/停止、加速、减速的快捷键
- **默认速度** - 拖动滑块设置启动时的初始速度
- **默认方向** - 选择向下或向上
- **浮层开关** - 控制是否显示速度指示器

## 安装

### Chrome / Edge

1. 下载扩展文件
2. 打开 `chrome://extensions/`（或 `edge://extensions/`）
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"，选择扩展目录

### Firefox

1. 下载扩展文件
2. 打开 `about:debugging#/runtime/this-firefox`
3. 点击"临时载入附加组件"，选择 `manifest.json`

## 兼容性

- Chrome 88+
- Edge 88+
- Firefox 109+
